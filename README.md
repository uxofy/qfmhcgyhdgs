# Animatium

Клиентский мод на **Fabric для Minecraft 1.21.11**, который убирает из
Настройки -> Управление лишние клавиши чужих модов:

- все бинды **MaceCore** (Backend, Drop Stack, Equip Elytra, Pearl Catch,
  Reset Target, Smartfi, Toggle Swapping) — вместе с красной плашкой MACECORE;
- **key.shieldbreaker.open_gui**.

## Важно: сами бинды продолжают работать

Бинды **не удаляются** из реестра — иначе они перестали бы нажиматься
(ваниль помечает нажатия перебором списка `KeyBinding.ALL`). Мод только
отменяет отрисовку строки в меню настроек, поэтому:

- скрытые функции MaceCore / ShieldBreaker работают как раньше;
- в списке на месте скрытых строк остаются небольшие пустые просветы.

Чтобы скрыть ещё какие-то клавиши — добавь их id в метод `shouldHide`
в `AnimatiumClient.java`.

## Сборка

### Через GitHub (ничего ставить не надо)

1. Создай репозиторий на GitHub и залей туда содержимое этого архива
   (корень архива = корень репозитория).
2. GitHub Actions автоматически соберёт мод: вкладка **Actions** ->
   последний запуск -> артефакт **animatium** -> скачай zip, внутри готовый `.jar`.
3. Забери jar из `build/libs` и кинь в папку `mods`.

### Локально

Нужна Java 21 и Gradle 8.10+:

```bash
gradle build
# или, если сгенерировал wrapper: ./gradlew build
```

Готовый jar: `build/libs/animatium-1.0.0.jar`.

## Если версии не совпали

Актуальные версии смотри на https://fabricmc.net/develop и поправь
`gradle.properties` (`fabric_version`, `loader_version`, `yarn_mappings`).
Если Mojang переименовали метод/поле в новом релизе — сборка упадёт с
ошибкой миксина; тогда скинь текст ошибки, поправлю.
